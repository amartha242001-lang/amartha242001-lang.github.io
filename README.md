# Portfolio Web - Erlangga Gilang Amartha

## Setup
1. Letakkan file foto Anda dengan nama `foto.jpg` di folder yang sama dengan `index.html`
2. Buka `index.html` di browser

## Struktur File
```
├── index.html      → Struktur halaman
├── style.css       → Styling modern
├── script.js       → Interaktivitas + modal sertifikat
├── foto.jpg        → Foto profil
└── README.md
```
